Frequently Asked Questions

Why are XML tags superior to Markdown headers for Claude?

Anthropic explicitly recommends XML tags because models understand opening and closing tag pairs (<tag>...</tag>) unambiguously, eliminating confusion when prompts contain user documents or conversational logs.

What happens to code blocks and special characters?

Code blocks (```python, ```json) are preserved character-for-character, ensuring that indentation and escaping are never broken.

How is the token savings percentage calculated?

Token savings are calculated using standard Byte-Pair Encoding (BPE) estimators comparing raw Markdown bytes and redundant blank lines against the structured, whitespace-compressed XML output.

Does this tool function completely offline?

Yes. All logic is self-contained and functions fully without an active internet connection.
